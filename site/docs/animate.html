animate()

Move an element, an object's numbers or one number. By default it is a spring that settles with no bounce. Give it a duration and it runs on an ease instead. Reduced motion, hidden tabs and a new target mid-flight are handled for you.

On an element, x and y (px), scale and rotate (degrees) make one transform, always in that order. A later animation of x keeps the y an earlier one left. It writes the element's transform, so keep your own offsets in the CSS translate property or on a wrapper.

Springs and eases

  • The default is a spring with period: 400 and damping: 1: as quick as it can be with no bounce. Higher damping is softer. Below 1 counts as 1, so it never overshoots.
  • A spring ends when it is within 0.5 of its target (or 0.5% of the way, for small values such as opacity). A 100 px move with the default takes about 470 ms.
  • duration turns the spring off. ease is 'out' (the default), 'in', 'inOut', 'linear', a cubic-bezier as [x1, y1, x2, y2], or your own function.
animate(el, { to: { x: 120 } }) // spring
animate(el, { to: { x: 120 }, period: 600, damping: 1.4 }) // slower, softer
animate(el, { to: { opacity: 0 }, duration: 200, ease: 'in' }) // a fixed time
animate(el, { to: { '--fill': 1 }, duration: 300, ease: [0.2, 0, 0, 1] }) // a custom property

Accessible by default

  • Reduced motion. With prefers-reduced-motion: reduce it lands on the end at once, delay and all. onUpdate runs once with the end values and onDone still runs, so the result is never lost. It is read live. Set motion: 'full' or 'reduce' to choose yourself.
  • Hidden tabs. Time stops while the tab is hidden, and it goes on from the same place when it comes back. If frames stall while the page is shown, a timer steps in, so it still ends on time.
  • Never layout. On an element it moves only transform, opacity and custom properties, which phones can draw without laying out the page again. Anything else, such as width, is skipped with a warning in the console.
  • No jump. A new animation of the same property takes over from where the old one is, at its speed. The old one's finished gives false.
  • Screen readers. Motion is not content. Keep the final words in the page, or say the result once in a polite live region from onDone, as the number above does.
