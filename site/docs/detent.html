detent()

One value under a hand. A slider, a dial, a picker wheel, a ruler and a sheet are all the same thing; only the path the hand takes changes.

import { detent } from '@hlmnhkl/detent'

const control = detent(el, { min: 0, max: 100, step: 10, marks: [50] })
