Getting started

detent makes the things people drag feel like they click into place: sliders, dials, wheels, sheets, the page scroll, a floating video, cards you throw, lists you pull and buttons you hold. Plain JavaScript, no dependencies, about 4 KB for a control.

Why detent

Vision. Every control on the web should feel as good as the best phone app, for everyone who uses it.

Mission. detent gives developers the feel of real, physical controls in a few lines of code: values that click into place, motion that never overshoots, and keyboard and screen reader support from the start. Small, free and open, so anyone can use it.

What we believe

  1. Feel is a feature. A slider that lands where you meant is better than one that looks good.
  2. Everyone, by default. If it does not work with a keyboard, a screen reader or reduced motion, it is not done.
  3. Never fight the hand. detent follows you. It never pulls the page or a control away from where you put it.
  4. No bounce for show. Things settle calmly, like a real knob clicking into its notch.
  5. Small enough to forget. A few kilobytes and no dependencies, so adding it is never a hard choice.
  6. Draw nothing. detent is the feeling, not the look. Your design stays yours.

Controls that click into place.

Install

npm install @hlmnhkl/detent

It works with any framework, or none. Nothing runs on import, so server rendering is safe.

A first slider

Give detent an element and a range. It wires the finger, the mouse, the keys and the screen reader. You draw it, here with one CSS variable.

The thumb reads the same variable:

.d-thumb { position: absolute; left: calc(var(--value) * 1%); translate: -50% 0; }

Drag it, flick it, or tab to it and press the arrow keys. 50 is strong, so it pulls from further away. Page Up and Page Down jump to it.

The functions at a glance

detent(el, options)One value under a hand: sliders, dials, picker wheels, rulers and sheets. detentScroll(options)The page settles onto its sections when the wheel or finger stops. detent2d(el, options)Drag something anywhere, and it settles onto the nearest point or corner. detentThrow(el, options)Drag a card past a line and it flies off that way. Short of it, it springs back. detentPull(el, options)Pull past a line to trigger, as in pull to refresh, without fighting the scroll. detentHold(el, options)Press and hold to confirm, on a fair clock. A tap asks for a confirm step.

Under them, every building block is public too. See Low level.

Reduced motion

With reduced motion turned on in the system, every control lands on the same value with no glide, and the page never settles by itself. It is read live, so a change applies at once.

Haptics

Every function that takes a hand can tick on phones that vibrate. It is off by default. haptics: true ticks only on strong marks and key moments: a pull that arms, a hold that completes, a throw past its line. haptics: 'all' also ticks every plain value, for wheels with few rows.

A tick is about 8 ms, a strong one about 12 ms, and never more than one every 80 ms. It ticks only for the person's own moves, never for go(). It works on Android, not on iPhone, because Safari has no vibration API. Use it for the clicks that matter, not every step.
