detent2d()

Drag something anywhere, and it settles onto the nearest point. A flick carries it toward where it was going. Arrow keys move it to the next point that way.

A box that snaps to corners

Video

Resting on: Top left. Screen readers hear: nothing yet.

.pip { position: absolute; left: 0; top: 0; translate: calc(var(--x) * 1px) calc(var(--y) * 1px); }

Keys and announcements

Tab to the box. The arrow keys move it to the next point in that direction, Home and End go to the first and last. When it lands, detent says the point's name in one shared polite live region, made when it starts, so screen readers do not miss it. announce: false turns that off.

Points can be your own, in px from the top-left of the bounds: points: [{ x, y, name: 'Dock', strong: true }].
