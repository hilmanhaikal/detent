scrollScene()

A scene is a timeline whose time is the page's scroll through a range. It only reads the scroll and never moves it, so the wheel, the finger and the keys stay the reader's. Scroll back and it plays back.

The range

start and end each name the target's edge, then the screen's edge: top, center, bottom or a percentage. The default runs from 'top bottom' (the target's top meets the screen's bottom) to 'bottom top' (its bottom leaves the top). It is measured from the page, not the box on screen, so the timeline can move the target itself. Resizes are read again.

Accessible by default

  • Never hijacks. It listens to the scroll and draws. It never stops the wheel, the finger or the keys, and it never scrolls the page by itself. Settling is yours to turn on, with detentScroll, and any hand stops a settle at once.
  • Never halfway. Each frame works out the time from where the page is, never from the last step, so a fast fling past the scene still lands on its end or its start.
  • Reduced motion. The scene jumps to its end as it comes in, and back to its start once it is gone above. Nothing moves with the scroll.
  • Content first. The words are in the page from the start. The scene only moves them, so a screen reader and find in page get everything.
  • Cheap. It reads the place of the target only on resize, and on scroll only reads scrollY, once per shared frame.
